# Weekly business reviews

One-page memos in the WBR template: headline with the number → scorecard (6 JD metrics vs last week and
4-week avg) → what drove it (revenue bridge, then the drill-down that isolates the cause) → impact →
recommendation with owner and date → watch list. Every number is read from the dbt marts; the matching
investigation notebook is in [`analysis/`](../analysis/). All data is simulated.
